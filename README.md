# chaoxing-auto-answer
学习通水课作业自动填答器,应该不会更新了（除非失效了）
作者B站账号：风予一下

使用方法

1：在浏览器中打开扩展页面，点击“加载解压缩的扩展”，选择解压好的zip文件夹

2：自己破解学习通作业网页版的复制粘贴限制，把题目丢给AI,自己整理答案的格式（或者自己事先准备好题库答案）

3：设置每题答题间隔，点开始填充的按钮，让它自己答题，最后面可以通过答题卡来看一下是不是都写好了（虽然基本上都可以写）

4；这个学习通自动答题的赛道好像早就满了，但是它们都是要通过skill,mcp，APIKey等花费，我这个你自己随便问网页版的国内免费AI弄到答案整理格式就可以用了。
